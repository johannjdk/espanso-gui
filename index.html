Espanso GUI is a native desktop editor for your Espanso match files. Create, review, and maintain text triggers, interactive form templates, and shell variables directly on disk without manual YAML formatting.

Features

Directly manages your existing Espanso match files without lock-in or proprietary storage.

Match File Management

Browse, create, rename, duplicate, and delete match files and individual triggers across your configuration folders.

Visual Form Editor

Create snippet forms with text fields, text areas, and choice dropdowns. Template tags like {{field}} are automatically detected.

Variable Support

Configure shell scripts, python commands, dates, clipboard values, and random choices in a clear master-detail view.

Global Search (Ctrl+F)

Quickly query triggers and templates across all YAML files with instant navigation directly to the match.

Expert YAML & Validation

Inspect raw documents for regex triggers or word flags. The built-in YAML parser validates syntax before saving to disk.

Profiles & Daemon Control

Edit default.yml, configure application filters, and restart the background Espanso daemon with one click.

Command-Line Installation

Install Espanso GUI using system package managers or run directly from Python source code.

bash — install-linux.sh 
curl -fsSL https://raw.githubusercontent.com/johannjdk/espanso-gui/main/scripts/install-linux.sh | sh

Automatically identifies Ubuntu, Debian, Arch Linux, or Fedora, downloads the latest release, and installs it.

bash — Debian / Ubuntu / Pop!_OS 
# Download standalone .deb (recommended for Ubuntu 22.04/24.04 and Pop!_OS):
sudo apt install ./espanso-gui-*-linux-debian-ubuntu-standalone.deb

# Or standard .deb (Ubuntu 24.10+ with system python3-pyside6):
sudo apt install ./espanso-gui-*-linux-debian-ubuntu.deb
bash — Arch Linux 
sudo pacman -U espanso-gui-qt-*-linux-arch.pkg.tar.zst
bash — Virtual Environment 
git clone https://github.com/johannjdk/espanso-gui.git
cd espanso-gui
python3 -m venv .venv
source .venv/bin/activate
pip install .
python3 -m espanso_gui

Requires Python 3.10+ and PySide6.
