Espanso GUI

A native desktop editor for Espanso match files. Espanso GUI makes it easier to create, review, and maintain text-expansion rules without editing YAML by hand, while keeping your existing Espanso configuration in control.

Installation via Terminal

Instructions for installing or running directly from source code.

Debian / Ubuntu 
sudo dpkg -i espanso-gui-qt-all.deb
sudo apt-get install -f
Arch Linux 
sudo pacman -U espanso-gui-qt-any.pkg.tar.zst
Run from Source

Requires Python 3.10+ and PySide6 

git clone https://github.com/johannjdk/espanso-gui-qt.git
cd espanso-gui-qt
python3 -m venv .venv
source .venv/bin/activate
pip install .
python3 -m espanso_gui_qt
